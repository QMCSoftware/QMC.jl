# Documentation Sources

This folder contains the Markdown pages that make up the QMC.jl documentation site.

## Current pages

- `index.md`: landing page and quick start.
- `components.md`: conceptual overview of the package building blocks.
- `demos.md`: notebook and example guide.
- `doctests.md`: deterministic Julia `jldoctest` examples mirroring common QMCPy workflows.
- `ci-testing.md`: CI, notebooks, and coverage workflow documentation.
- `workflow-debugging.md`: local linting and smoke-run workflow debugging guide.
- `contributing.md`: contributor guidance.
- `community.md`: project/community information.

API reference pages live under `docs/src/api/` and are paired with docstrings from `src/`.
