Kernels

Abstract Types

QMC.AbstractKernel — Type

Abstract base for all kernels.

QMC.AbstractStationaryKernel — Type
AbstractStationaryKernel <: AbstractKernel

Abstract supertype for stationary (distance-based) kernels. Subtypes must implement kernel_eval(k, r::Float64) where r is the Euclidean distance.

Shift-Invariant Kernels

QMC.KernelShiftInvar — Type
KernelShiftInvar(; order=2)

Shift-invariant kernel for lattice rules, diagonalized by the DFT (FFT).

The 1D kernel of order r is: $K_r(x) = 1 + (-1)^{r+1} \frac{(2\pi)^{2r}}{(2r)!} B_{2r}(\{x\})$

where $B_{2r}$ is the Bernoulli polynomial and $\{x\}$ is the fractional part. The multivariate kernel is a product: $K(\mathbf{x}) = \prod_j K_r(x_j)$.

For a rank-1 lattice the kernel matrix is circulant, so its eigenvalues are obtained via a single FFT of the first column.

Example

kernel = KernelShiftInvar(order=2)
eigenvalues = compute_kernel_eigenvalues(kernel, lattice_points)
QMC.KernelDigShiftInvar — Type
KernelDigShiftInvar(; order=2)

Digitally shift-invariant kernel for digital net (base 2) rules. Diagonalized by the Walsh-Hadamard Transform (WHT).

$K(\mathbf{x}, \mathbf{y}) = K(\mathbf{x} \oplus \mathbf{y})$

where $\oplus$ is the bitwise XOR operation on the binary representations. The 1D kernel of order r is based on Walsh series coefficients.

Example

kernel = KernelDigShiftInvar(order=2)
eigenvalues = compute_kernel_eigenvalues(kernel, sobol_points)

Matérn and Gaussian Kernels

QMC.KernelMatern12 — Type
KernelMatern12(; lengthscale=1.0, outputscale=1.0)

Matérn-1/2 (exponential) kernel: k(r) = σ² exp(-r/ℓ).

QMC.KernelMatern32 — Type
KernelMatern32(; lengthscale=1.0, outputscale=1.0)

Matérn-3/2 kernel: k(r) = σ² (1 + √3 r/ℓ) exp(-√3 r/ℓ).

QMC.KernelMatern52 — Type
KernelMatern52(; lengthscale=1.0, outputscale=1.0)

Matérn-5/2 kernel: k(r) = σ² (1 + √5 r/ℓ + 5r²/(3ℓ²)) exp(-√5 r/ℓ).

QMC.KernelGaussian — Type
KernelGaussian(; lengthscale=1.0, outputscale=1.0)

Gaussian (RBF / squared exponential) kernel: k(r) = σ² exp(-r²/(2ℓ²)).

QMC.KernelRationalQuadratic — Type
KernelRationalQuadratic(; lengthscale=1.0, outputscale=1.0, alpha=1.0)

Rational-quadratic kernel: k(r) = σ² (1 + r²/(2 α ℓ²))^(-α), the scale-mixture of Gaussian kernels with mixture parameter alpha (α > 0). As alpha → ∞ it converges to the Gaussian (RBF) kernel σ² exp(-r²/(2ℓ²)).

Matches QMCPy's KernelRationalQuadratic: with distance d_γ = ‖(x - z)/(√2 ℓ)‖₂, k = σ² (1 + d_γ²/α)^(-α) = σ² (1 + r²/(2 α ℓ²))^(-α).

QMC.KernelSquaredExponential — Type
KernelSquaredExponential(; lengthscale=1.0, outputscale=1.0)

Squared-exponential kernel: k(r) = σ² exp(-r²/(2ℓ²)). Mathematically identical to KernelGaussian; provided as a distinct type for naming parity with QMCPy's KernelSquaredExponential (which expresses the same kernel via the pairwise-distance form S exp(-d_γ²), d_γ = ‖(x - z)/(√2 ℓ)‖₂).

Combined Kernels

QMC.SumKernel — Type
SumKernel(k1::AbstractKernel, k2::AbstractKernel)

Sum of two kernels: k(r) = k₁(r) + k₂(r).

QMC.ProductKernel — Type
ProductKernel(k1::AbstractKernel, k2::AbstractKernel)

Product of two kernels: k(r) = k₁(r) · k₂(r).

QMC.KernelMultiTask — Type
KernelMultiTask(base_kernel, num_tasks; factor, diag)

Multi-task (multi-output) kernel:

K((i,x), (j,z)) = Ktask(i,j) · Kbase(x,z)

where the task correlation matrix is

K_task = F · F' + diag(v)

with factor matrix F ∈ ℝ^{T×r} and diagonal v ∈ ℝ^T.

Arguments

  • base_kernel::AbstractKernel: spatial kernel K_base(x, z)
  • num_tasks::Int: number of tasks T
  • factor::Matrix{Float64}: factor matrix F (T × r), default zeros(T, 1)
  • diag::Vector{Float64}: diagonal v, default ones(T)

Example

base = KernelGaussian(2)
kmt = KernelMultiTask(base, 3; diag=[1.0, 2.0, 3.0])
# Task correlation matrix is I + diag([1,2,3])

Kernel Operations

QMC.compute_kernel_eigenvalues — Function
compute_kernel_eigenvalues(kernel::KernelShiftInvar, x::AbstractMatrix) -> Vector{Float64}

Compute eigenvalues of the circulant kernel matrix for lattice points x (n×d) using FFT. Returns a vector of n real eigenvalues.

compute_kernel_eigenvalues(kernel::KernelDigShiftInvar, x::AbstractMatrix) -> Vector{Float64}

Compute eigenvalues of the kernel matrix for digital net points x (n×d) using Walsh-Hadamard Transform. Returns a vector of n eigenvalues.

QMC.kernel_eval — Function
kernel_eval(k::AbstractStationaryKernel, r::Float64) -> Float64

Evaluate kernel k at distance r. Each kernel subtype has its own method.

kernel_eval(kmt::KernelMultiTask, task_i, task_j, x, z)

Evaluate K((taski, x), (taskj, z)) = taskmat[taski, taskj] * K_base(x, z). Task indices are 1-based.

QMC.kernel_matrix — Function
kernel_matrix(k::AbstractStationaryKernel, x::AbstractMatrix) -> Matrix{Float64}

Build the n×n kernel matrix K[i,j] = k(‖xᵢ - xⱼ‖) for points x (n × d).

kernel_matrix(kmt::KernelMultiTask, tasks, X)

Build the full (T·n) × (T·n) kernel matrix for tasks ∈ 1:T and data X (n × d). Rows/columns are ordered as (task1, x1), (task1, x2), ..., (taskT, xn).
