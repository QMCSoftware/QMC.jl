# Integrands

This folder contains the functions and application models integrated by the stopping criteria.

## Categories

- classical QMC test functions such as `Keister`, `Genz`, `BoxIntegral`, `Linear0`, and `Sin1D`
- reliability and sensitivity examples such as `Ishigami`, `FourBranch2D`, and `SensitivityIndices`
- financial models including `FinancialOption`, `AsianOption`, and `FinancialOptionML`
- infrastructure types such as `CustomFun`, `UMBridgeWrapper`, and `ml_integrand.jl`

Many files here also expose exact-value helpers used in tests and benchmark smoke checks.
